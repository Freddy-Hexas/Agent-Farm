# Agent Farm 0.5.0.8 preview package

This directory contains the self-contained Windows x64 package built from the 0.5.0.8 source. It
includes the native WinUI 3 client, .NET/Windows App SDK runtime files, and the frozen Python product
backend.

## Files

- `AgentFarm-Native-x64.msix` — self-contained, development-signed preview installer.
- `AgentFarm-dev.cer` — public development certificate for the checked-in preview package.
- `SHA256SUMS.txt` — hashes for the MSIX and generated AppInstaller metadata.
- `AgentFarm-stable.appinstaller` — production channel metadata generated by the release pipeline.
  It becomes a one-click upgrade feed only after the same signed assets are published to the Stable
  GitHub Release channel.

## Install the repository preview

1. Verify `AgentFarm-Native-x64.msix` against `SHA256SUMS.txt`.
2. Inspect `AgentFarm-dev.cer`, then import it into the current user's **Trusted People** store:

```powershell
Import-Certificate `
  -FilePath .\AgentFarm-dev.cer `
  -CertStoreLocation Cert:\CurrentUser\TrustedPeople
```

3. Double-click `AgentFarm-Native-x64.msix` and choose **Install**.
4. Launch **Agent Farm** from the Start menu.

This development certificate is not the production trust model. The protected release workflow
rejects self-signed certificates, requires a CA-issued PFX, adds a trusted timestamp, installs the
result on a clean CI runner, and publishes fixed Stable/Preview update assets.
